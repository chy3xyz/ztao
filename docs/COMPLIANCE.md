# ztao · 国内 SaaS 合规清单

> ztao 首发市场 = 中国大陆。SaaS 公网部署 + 微信小程序 + 微信支付 v3 + 支付宝 + 订阅消息。
> 本文是 M1 验收前必须准备到位的清单。

---

## 1. 微信小程序（用户主端）

### 1.1 注册主体

| 类型 | 适用 | 备注 |
|---|---|---|
| **个人主体** | M1 体验号 / 内测 | 不可支付 / 不可订阅消息，**M4 转企业** |
| **企业主体** | M2+ 公测 / 上线 | 必选；需营业执照 |

**M1 用体验号快速跑通；M4 转企业主体。**

### 1.2 小程序类目

| 模块 | 类目 | 备注 |
|---|---|---|
| 主体 | **工具 → 效率** | 一人公司 PM 工具归属 |
| 商城 | **商家自营 → 办公/文具/礼品** | 配件 / 礼品商城 |
| 商城 | **IT 科技 → 云服务/算力** | 算力商城（订阅 / Token 包） |
| AI | **工具 → 效率** 子类 | 不需要单独类目 |
| 内容 | **文娱 → 其他**（可选） | 文档发布时 |

> 商城类目必须企业主体；M1 用体验号不带商城；M4 转企业后开通。

### 1.3 用户协议 + 隐私政策

- 首次启动弹出《用户协议》《隐私政策》两个页面（必须用户点击同意）
- 协议里必须包含：数据收集范围（openid / unionid / 手机号 / Token 用量 / 商城订单）/ 数据存储位置 / 数据出境 / 注销路径
- 法规依据：《个人信息保护法》《数据安全法》《网络安全法》
- 文案模板：参考 Teambition / Notion 中文版

### 1.4 订阅消息（推送）

8 个场景模板（用户主动勾选，可零选）：

| 场景 | 模板标题 | 关键词 | 触发时机 |
|---|---|---|---|
| 任务被分配给我 | 任务分配通知 | 任务名 / 项目名 / 分配人 | task.assigned_to=me |
| 任务被 @ | 任务评论通知 | 任务名 / 评论人 / 评论摘要 | comment.mentioned=me |
| Bug 紧急 | 紧急缺陷通知 | Bug 名 / 严重度 / 指派人 | bug.created severity>=严重 |
| AI 完成 | AI 任务完成 | 任务名 / 耗时 / 摘要 | agent_run.finished |
| AI 需要审批 | AI 操作审批 | 工具名 / 操作描述 | agent_approval.requested |
| 算力不足 | Token 余量预警 | 余量 / 推荐套餐 | quota.threshold_hit |
| 商城订单状态 | 订单状态通知 | 订单号 / 状态 | order.status_changed |
| 团队里程碑达成 | 里程碑达成 | 项目名 / 完成率 / 时间 | milestone.completed |

> 每个模板需在 [微信公众平台](https://mp.weixin.qq.com) → 订阅消息 → 公共模板库 选/申请。
> 类目"工具 → 效率"已包含大部分；个别需单独申请。

### 1.5 内容安全

- `wx.request` 自带 `msgSecCheck`（文字）/ `imgSecCheck`（图片）
- 用在：Bug 描述、AI 输出、评论、用户昵称
- 频率：每次写操作至少一次

### 1.6 强制规范

- 不诱导分享（"分享到朋友圈领奖"）
- 不强制关注公众号
- 支付类目合规（实物 / 虚拟商品 / 订阅 三档）
- 客服必须有"联系客服"按钮（接 WebView 客服或小程序客服组件）

### 1.7 注销与数据出境

- 我的 → 设置 → 注销账号：30 天冷静期；过期后真删（去标识化）
- 我的 → 数据出境：一键导出 JSON（含项目、任务、Bug、订单、Agent Run 等）

## 3. 域名与备案

| 域名 | 用途 | 备案 |
|---|---|---|
| `api.ztao.cn` | 后端 API | 必备案 |
| `admin.ztao.cn` | Web 后台 | 必备案 |
| `ztao.cn` | 主站 | 必备案 |

- 备案周期：7~20 个工作日
- **M1 用 ngrok / cloudflare tunnel 临时调试**，避免阻塞开发
- 验收前切换正式域名 + SSL

### SSL

- Let's Encrypt（免费、自动续期）
- 或阿里云 SSL（国内 CDN 友好）
- Nginx 反代 + TLS 1.3

## 5. 微信支付 v3

### 5.1 主体

- 必须是**企业主体**
- 需《营业执照》《开户许可证》《法人身份证》

### 5.2 申请流程

1. 微信支付商户号申请（已注册企业主体的小程序自动开通入口）
2. 配置 API v3 密钥（每 90 天建议轮换）
3. 配置 API 证书（apiclient_cert.pem / apiclient_key.pem）
4. 配置回调 URL（`https://api.ztao.cn/api/v1/pay/v3/notify`）

### 5.3 类目

| 业务 | 微信支付类目 | 费率 |
|---|---|---|
| 订阅（Lite/Pro/Team） | 数字商品 → 软件服务 | 1%~2% |
| 算力包 | 数字商品 → 软件服务 | 1%~2% |
| 配件（实物） | 实物商品 | 1% |
| 礼品（实物） | 实物商品 | 1% |

### 5.4 接入（沿用 zweq/payment）

- zweq 已实现 `prepay` + `notify` 验签
- ztao M4 直接复用 + 扩展 `ComputeOrder` 走 RechargeOrder 流程
- **M1 不接支付**，先打通登录

## 8. 数据合规

### 8.1 用户数据

| 数据 | 存储 | 加密 | 出口 |
|---|---|---|---|
| openid / unionid | 明文 | — | 用户删除即删 |
| 手机号 | 加密 | AES-256 | 脱敏展示 |
| 邮箱 | 明文（小写） | — | 用户删除即删 |
| 头像 / 昵称 | OSS + URL | — | URL 失效 |
| Token 用量 | 明文 | — | 数据出境可导出 |
| AI 对话 | 明文 + 摘要 | — | 数据出境可导出 |

### 8.2 内容合规

- AI 输出的内容走 `msgSecCheck`（异步）
- 用户上传图片走 `imgSecCheck`（异步）
- 评论 / 任务描述 / Bug 重现 → 实时 `msgSecCheck`

### 8.3 数据保留

- 活跃用户数据永久保留
- 注销用户 30 天后删除（去标识化）
- 审计日志保留 1 年（合规要求）

---

## 9. 税务与发票

- 企业主体必须能开**增值税普通发票 / 专用发票**
- M5 接入：用户在小程序"我的"→ 申请发票，财务后台 → 审核 → 开具 → 邮件发送 PDF
- 微信支付订单可走微信官方"电子发票"（需企业主体申请）
- 个人开发者场景暂不开票

---

## 10. 用户协议必备条款

1. 数据收集清单（具体到字段）
2. 数据使用范围（仅用于产品功能）
3. 第三方共享清单（OSS / 微信支付 / AI Provider / 七牛）
4. 用户权利（查看 / 导出 / 删除 / 撤回授权）
5. 数据存储位置（中国大陆）
6. 未成年人保护（不向 14 岁以下提供服务）
7. 协议变更通知方式
8. 争议管辖（约定法院）

> 模板可参考 Notion 中国版 / 飞书 / Teambition。
