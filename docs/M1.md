# ztao · M1 施工图

> **M1 = 骨架 + 小程序登录 + AI 入口（2 周）**
>
> 锁定的关键选型：
> - **M1 顺序**：先打通小程序登录 + AI 入口
> - **小程序框架**：**Taro 4 + React + TS**
> - **支付**：国内为主（微信支付 v3 + 支付宝，留接口给 Stripe）
> - **部署**：SaaS 公网
>
> 目标：注册 1 分钟内拿到一家"数字公司" + 5 名 AI 员工 + 小程序入口。

---

## 0. M1 交付目标（Definition of Done）

✅ 一个能跑通的 SaaS 骨架：

1. **后端**（zweq/Zig）：启动后能听 `https://api.ztao.cn` 端口，Postgres 已建库，已自动迁移到 M1 schema
2. **小程序**（Taro 4）：能在微信开发者工具里跑起来，扫码登录 → 自动建 Tenant + 5 Agent → 看到 AI 团队卡片
3. **AI 入口**：5 个 Agent 模板（pm / dev / qa / support / ops）已注册 schema + 出现在小程序
4. **Web 后台**（最简版）：登录页 + 首页占位（能登录进控制台）
5. **部署**：`docker compose up` 即可；CI 跑通 `zig build test` + `mp npm run typecheck`

### 2.5 一人公司引导流（核心）

```zig
//! src/modules/onboarding/service.zig
//!
//! 首次 wx.login 成功后调用，自动完成：
//! 1) 找/建 Tenant （以 openid 散列做 slug 防冲突）
//! 2) 找/建 User（用 UserIdentity 绑定）
//! 3) 建默认 Workspace（kind='solo'）
//! 4) 注入 5 个 AgentInstance（基于 AgentPreset）
//! 5) 落 OnboardingState.step='agents_ready'
//! 6) 返回 JWT（tid + uid + role + workspace_id + agent_ids[]）

pub const OnboardingService = struct {
    fn bootstrapFromMp(self, code, encryptedData, iv) !OnboardResult {
        // 1. jscode2session → { openid, unionid, session_key }
        const wx = try self.wxClient.code2session(code);
        // 2. 查找/创建 UserIdentity + User
        const user = try self.identitySvc.findOrCreate('wechat-mp', wx.openid, wx.unionid);
        // 3. 查找/创建 Tenant + Workspace
        const ctx = try self.workspaceSvc.ensureSoloWorkspace(user.id);
        // 4. 注入 5 个 Agent 实例（幂等）
        const agents = try self.agentSvc.clonePresetsToUser(ctx.tenant_id, user.id);
        // 5. 落引导状态
        try self.repo.upsertOnboarding(user.id, .agents_ready);
        // 6. 发 JWT
        const token = try self.jwtSvc.issue(user, ctx);
        return .{ .user = user, .tenant = ctx.tenant, .workspace = ctx.workspace,
                 .agents = agents, .token = token };
    }
};
```

### 3.6 类型与请求封装

```ts
// services/http.ts
const http = {
  async request<T>(method: string, path: string, body?: any): Promise<T> {
    const token = Taro.getStorageSync('ztao_token');
    const res = await Taro.request({
      url: `${API_BASE}${path}`,
      method, data: body,
      header: { Authorization: token ? `Bearer ${token}` : '', 'X-Mp-AppId': APP_ID },
    });
    const env = res.data as Envelope<T>;
    if (env.code !== 0) throw new ApiError(env.code, env.msg);
    return env.data;
  },
  get: <T>(p: string) => http.request<T>('GET', p),
  post: <T>(p: string, b?: any) => http.request<T>('POST', p, b),
};

// types
type Envelope<T> = { code: 0 | number; msg: string; data: T };
```

### 4.2 AgentInstance 注入

```zig
// src/modules/agent/service.zig
pub fn clonePresetsToUser(svc, tenant_id, user_id) ![]AgentInstance {
    const presets = try svc.store.listPresets(is_default=true);
    var out = std.ArrayList(AgentInstance).init(svc.allocator);
    for (presets) |p| {
        const exists = try svc.store.findInstanceByPreset(tenant_id, user_id, p.id);
        if (exists != null) continue;
        const inst = try svc.store.insertInstance(.{
            .tenant_id, .user_id, .preset_id = p.id,
            .name = p.name, .avatar_override = p.avatar,
            .tools_override = null, .scopes_override = null,
            .status = .active, .memory_policy = "session",
            .max_daily_cost_cents = 5000,  // ¥50 / 日硬上限
        });
        out.append(inst);
    }
    return out;
}
```

## 8. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 微信小程序体验号不能走支付 | M1 只做登录 + AI 入口，不接支付；M4 切换正式小程序 |
| wx.login 被风控 | 加 `unionid` 兜底；用户换微信号能找回 |
| 一人公司引导失败导致数据脏 | 全部用"找/建"幂等；重复调用安全 |
| AI 入口是 stub 用户觉得被骗 | 文案明确"M1 占位 · M3 接真实模型"；前端标灰 |
| 域名 / ICP / SSL 没准备好 | 用 `*.ngrok.io` 临时调试；M1 验收前切换 |
| Postgres 启动报错 | docker-compose 里挂载 init.sql；CI 加 `pg_isready` 健康检查 |
